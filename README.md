# ScreenImageMonitor v1.0 かんたん操作ガイド

このアプリは、Windows画面の一部分を自動で見張り、次のどちらかを検出して回数を数えるアプリです。

- 画面に表示された数字を読み取る
- 登録したPNG／JPEG画像が表示されたか確認する

条件に一致したときは、カウントアップに加えて音を鳴らすこともできます。操作は `ScreenImageMonitor.exe` の画面内だけで行います。

---

## 最初に行うこと

1. `ScreenImageMonitor.exe`をダブルクリックします。
2. 「設定・ルール編集」を開きます。
3. 「数字OCRルール追加」または「画像一致ルール追加」を押します。
4. 監視する場所と判定条件を設定します。
5. 「ルールへ反映」を押します。
6. 「設定を保存」を押します。
7. メイン画面へ戻り、「監視開始」を押します。

> **OCRとは**
> 画面に表示された数字を文字として読み取る機能です。

---

# 数字を読み取って数える場合

## 1. 数字ルールを追加する

設定画面で次を押します。

```text
数字OCRルール追加
```

「ルール名」には、何を数えるルールなのか分かる名前を入力します。

例：

```text
警告数値
処理件数
スコア増加回数
```

## 2. 数字が表示される場所を指定する

次を押します。

```text
画面から範囲選択
```

監視したい数字の部分をマウスで囲みます。

- 左ボタンを押したままドラッグ：範囲を選択
- 左ボタンを離す：確定
- `Esc`または右クリック：キャンセル

文字だけでなく、数字の周囲に少し余白を含めると読み取りが安定しやすくなります。

## 3. 数値条件を選ぶ

数値条件は日本語で表示されます。用途に合うものを選択してください。

| 画面の表示 | 意味 | 入力例 |
|---|---|---|
| 指定した数値と同じ | 読み取った数値が指定値と同じとき | `10` |
| 指定した数値と異なる | 読み取った数値が指定値以外のとき | `0` |
| 指定した数値より大きい | 読み取った数値が指定値を超えたとき | `10` |
| 指定した数値以上 | 読み取った数値が指定値以上のとき | `10` |
| 指定した数値より小さい | 読み取った数値が指定値未満のとき | `10` |
| 指定した数値以下 | 読み取った数値が指定値以下のとき | `10` |
| 指定範囲内 | 読み取った数値が指定範囲内のとき | `1-10` |
| OCR結果に指定範囲の数値を含む | OCR結果に含まれる数値のどれかが範囲内のとき | `120-129` |
| 前回から数値が変わった | 安定して読み取った数値が前回から変化したとき | 入力不要 |
| 前回より数値が増えた | 安定して読み取った数値が前回より増加したとき | 入力不要 |
| 前回より数値が減った | 安定して読み取った数値が前回より減少したとき | 入力不要 |

### 範囲の入力方法

範囲は1つの入力欄へ、次のように入力します。

```text
1-10
```

小数も使用できます。

```text
1.5-9.5
```

### OCR結果に範囲内の数値を含む

OCR結果に複数の数値や小数が含まれる場合に使用します。

設定例：

```text
数値条件：OCR結果に指定範囲の数値を含む
含まれる範囲：120-129
```

OCR結果が次の場合、`121.1`が`120-129`の範囲内なので検知します。

```text
121.1
```

OCR結果に複数の数字がある場合も、範囲内の数字が1つでもあれば検知します。

### よく使う条件

数字が増えた回数を数える場合：

```text
前回より数値が増えた
```

100以上になった回数を数える場合：

```text
数値条件：指定した数値以上
判定値：100
```

1～10の範囲を検知する場合：

```text
数値条件：指定範囲内
範囲：1-10
```

## 4. 読み取りを確認する

次を押します。

```text
数字OCRテスト
```

表示された結果が、実際の画面上の数字と合っていることを確認します。

正しく読めない場合は、監視範囲を選び直してください。

# 登録画像が表示された回数を数える場合

## 1. 画像ルールを追加する

設定画面で次を押します。

```text
画像一致ルール追加
```

## 2. 判定に使う画像を登録する

次を押します。

```text
PNG/JPEGを登録...
```

使用できる画像形式は次のとおりです。

```text
.png
.jpg
.jpeg
```

登録画像がない場合、画像ルールは保存・開始できません。画面に案内が表示されたら、先に画像を登録してください。

画像ファイル名や保存フォルダーには日本語を使用できます。

## 3. 監視する位置を指定する

画像を登録すると、登録画像と同じ大きさの枠が画面に表示されます。

1. マウスを動かして、枠を監視対象へ合わせます。
2. 左クリックで位置を確定します。
3. `Esc`または右クリックでキャンセルできます。

枠の大きさは登録画像と自動的に同じになるため、手動で大きさを合わせる必要はありません。

## 4. 画像一致率を設定する

画像一致率は、「登録画像と現在の画面がどの程度似ていれば同じ画像と判断するか」の設定です。

| 設定値 | 判断の厳しさ |
|---|---|
| `0.95` | かなり厳しい。ほぼ同じ画像だけを検出 |
| `0.90` | 標準的な設定 |
| `0.80` | 少し違っていても検出しやすい |

まずは次の値から試してください。

```text
0.90
```

誤検出が多い場合は値を上げ、検出しない場合は少し下げます。

## 5. 画像の判定を確認する

次を押します。

```text
画像一致テスト
```

一致率と検出位置が表示されます。現在画面に対象画像が表示されている状態で、設定した一致率を超えることを確認してください。

# 共通の設定

## 連続一致回数

同じ条件が何回続いたらカウントするかを指定します。

例：

```text
2
```

この場合、2回続けて条件に一致したときにカウントします。一瞬だけ表示されるノイズによる誤検出を減らせます。

通常は次の設定を推奨します。

```text
2
```

見逃しが発生する場合は`1`を試してください。

## 音を鳴らす

次にチェックを入れると、カウントアップ時に音が鳴ります。

```text
カウントアップ時に音通知する
```

音声ファイルは次を使用します。

```text
sounds/alert.wav
```

音を変更する場合は、同じファイル名のWAVファイルへ差し替えてください。

## 証跡画像を保存する

次にチェックを入れると、カウントした瞬間の画面を保存します。

```text
カウントアップ時に証跡スクリーンショットを保存する
```

保存先は次です。

```text
evidence
```

# 監視を開始する

設定を保存した後、メイン画面で次を押します。

```text
監視開始
```

監視中は、各ルールの「判定詳細」に次の情報が表示されます。

- 最後に確認した時刻
- 画面を確認した回数
- 読み取った数字、または画像の一致率
- 1回の確認にかかった時間

確認回数と時刻が更新され続けていれば、監視は動作しています。

監視を終了する場合は次を押します。

```text
監視停止
```

# カウンター画面

カウント数は、メイン画面とは別のカウンター画面に大きく表示されます。初期状態は、見本画像に近い**細い白文字と青い背景**です。

カウンター画面では次の操作ができます。

- ルールごとのカウント確認
- 各ルールの「0に戻す」で個別クリア
- 「全カウントをクリア」で一括クリア
- カウンター文字のフォント変更

カウンター画面を閉じた場合は、メイン画面の次のボタンから再表示できます。

```text
カウンター表示
```

## カウンターのフォントを変更する

カウンター画面右上の次のボタンを押します。

```text
フォント設定
```

変更できる項目は次のとおりです。

| 項目 | 内容 |
|---|---|
| フォント | Windowsにインストールされているフォントから選択 |
| 文字サイズ | `18`～`180`の範囲で指定 |
| 太字にする | 必要な場合だけチェック |

設定画面には`1234`のプレビューが表示されます。「保存」を押すと、開いているすべてのカウンターへすぐに反映されます。

見本画像に近い初期設定は次のとおりです。

```text
フォント：Segoe UI Light
文字サイズ：56
太字：なし
```

`Segoe UI Light`がPCにない場合は、`Segoe UI`または`Arial`が自動的に使用されます。フォントファイルを別途用意する必要はありません。

フォント設定は次のファイルへ保存され、次回起動時も引き継がれます。

```text
counter_display.json
```

カウントはアプリを終了しても保存されます。


# うまく動かない場合

## 数字を正しく読めない

- 数字だけが入るように監視範囲を選び直します。
- 数字の周囲に少し余白を含めます。
- 背景と文字の色が近い場合は、なるべく数字がはっきり表示された状態で試します。
- 「数字OCRテスト」で結果を確認します。

## 画像を検出しない

- 登録画像と監視対象の大きさが同じか確認します。
- 対象が表示されている状態で「画像一致テスト」を実行します。
- 一致率を`0.90`から`0.85`程度へ少し下げて試します。
- 画面拡大率やアプリの表示倍率が変わると、登録画像と一致しにくくなります。

## 同じ表示を何度もカウントしない

同じ画像や同じ条件が表示され続けている間は、通常1回だけカウントします。一度条件から外れ、再び条件に一致したときに次のカウントが行われます。

## 監視が止まっているように見える

メイン画面の「判定詳細」で、確認時刻と確認回数が更新されているか確認します。更新されていない場合は、一度「監視停止」を押してから「監視開始」を押してください。

# GitHub ActionsでEXEを作る

GitHubにファイル一式を登録した後、次の順に操作します。

1. GitHubリポジトリの`Actions`を開きます。
2. 左側の`Build Windows Integrated GUI EXE`を選びます。
3. `Run workflow`を押します。
4. 緑色の`Run workflow`をもう一度押します。
5. 緑のチェックになるまで待ちます。
6. 実行結果を開き、画面下部の`Artifacts`からダウンロードします。

Artifact名：

```text
ScreenImageMonitor-Windows-GUI-v1.0
```

ダウンロードしたZIPを展開し、次を起動します。

```text
ScreenImageMonitor.exe
```
