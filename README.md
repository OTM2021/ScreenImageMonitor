# ScreenImageMonitor 統合GUI版

`ScreenImageMonitor.exe`をダブルクリックすると、操作画面が直接開きます。BATファイルやコマンドプロンプト操作は不要です。

## GUIでできること

- 監視開始・停止
- 数字OCR／画像一致のリアルタイム状態確認
- カウント値の確認
- 選択したカウントだけクリア
- 全カウントのクリア
- 設定画面の表示
- マウスドラッグによる監視領域選択
- 現在画面からテンプレート画像を取り込み
- 現在画面からOCR確認用スクリーンショットを取り込み
- OCR結果／画像一致率のテスト
- 条件成立時の証跡画像フォルダーを表示

## 初回設定

1. `ScreenImageMonitor.exe`を起動します。
2. メイン画面の「設定・領域選択」を押します。
3. ルールを追加または選択します。
4. 「画面からドラッグ選択」を押します。
5. 表示された画面上で監視対象をドラッグし、Enterで確定します。
6. 「現在の選択領域を取り込む」を押します。
   - 数字OCRルールでは確認用画像を`samples`へ保存します。
   - 画像一致ルールでは比較用画像を`templates`へ保存します。
7. 「OCR／画像一致テスト」で認識結果を確認します。
8. 「ルールへ反映」→「config.jsonへ保存」の順に押します。
9. 設定画面を閉じ、メイン画面で「監視開始」を押します。

## メイン画面

| 操作 | 内容 |
|---|---|
| 監視開始 | 登録ルールの監視を開始します。 |
| 監視停止 | OCRまたは画像監視を停止します。 |
| 設定・領域選択 | 設定GUIを開きます。監視中の場合は自動停止後に開きます。 |
| 設定再読込 | `config.json`と`counts.json`を再読込します。 |
| 選択カウントをクリア | 一覧で選択したカウントルールを0にします。 |
| 全カウントをクリア | すべてのカウントを0にします。 |
| 証跡画像を開く | 条件成立時に保存された画像フォルダーを開きます。 |

## GitHub ActionsでEXEを作成

リポジトリへ全ファイルを配置し、GitHubの次の画面を開きます。

1. `Actions`
2. `Build Windows Integrated GUI EXE`
3. `Run workflow`

完了後、実行結果のArtifactsから次をダウンロードします。

```text
ScreenImageMonitor-Windows-GUI
```

ZIPを展開し、`ScreenImageMonitor.exe`を起動してください。

## 注意事項

- Windowsの表示倍率やアプリの拡大率を変更すると画像一致率が変わる場合があります。
- OCR対象は数字だけが入るように狭く選択すると認識精度が上がります。
- 監視中に設定を開くと、監視を停止してから設定画面を開きます。
- `counts.json`と`monitor.log`は実行時にEXEと同じフォルダーへ作成されます。
