# ScreenImageMonitor 統合GUI版 v6.3

Windows画面の指定範囲を常駐監視し、数字OCRまたは登録画像との一致を検出してカウントするGUIアプリです。音通知は各カウントルールのチェック項目として設定します。操作は `ScreenImageMonitor.exe` だけで完結し、BATファイルは使用しません。

## v6.3の変更内容

- 範囲選択画面を設定GUIと同じプロセスで開く方式から、独立した選択専用プロセスへ変更
- 設定画面のモーダル制御、前面表示、`grab_set()` の状態に影響されず選択画面を表示
- 選択専用プロセスでは、選択対象モニター全体をTkのルートウィンドウとして直接表示
- メイン画面と設定画面のボタン名を「画面から範囲選択」へ統一
- 複数モニターおよび負のデスクトップ座標に対応

## 画面から範囲選択

メイン画面では、監視一覧から対象ルールを選択して次を押します。

```text
画面から範囲選択
```

設定画面内にも同名のボタンがあります。押すと設定画面が一時的に隠れ、選択対象モニター上に独立した全画面オーバーレイが表示されます。

1. 監視したい範囲を左ドラッグします。
2. マウスボタンを離すと範囲が確定します。
3. 設定画面へ戻り、選択範囲のプレビューと座標が表示されます。

取消操作は次のとおりです。

- `Esc`
- 右クリック

## ルール設定

### 数字OCR

1. 「数字OCRルール追加」を押します。
2. 「画面から範囲選択」で数字部分を指定します。
3. 数値条件を設定します。
4. 必要な場合は「カウントアップ時に音通知する」をチェックします。
5. OCRテスト後に保存します。

### 画像一致

1. 「画像一致ルール追加」を押します。
2. PNG、JPGまたはJPEG画像を事前登録します。
3. 「画面から範囲選択」で検索対象範囲を指定します。
4. 画像一致率を設定します。
5. 必要な場合は「カウントアップ時に音通知する」をチェックします。
6. 画像一致テスト後に保存します。

画像ルールはOCRを実行せず、登録画像とのOpenCV画像一致だけを判定します。登録画像がない場合は、保存時および監視開始時に登録を促します。

## 音通知

音通知に使用する標準ファイルは次です。

```text
sounds/alert.wav
```

- チェックなし：カウントのみ
- チェックあり：カウント＋音通知

## 常駐監視

ルールごとに独立した監視スレッドを使用します。OCR処理中でも別の画像一致ルールは継続して走査します。メイン画面の判定詳細には、最終更新時刻、走査回数および処理時間が表示されます。

## カウンターポップアップ

EXE起動時に別ウィンドウで表示されます。数字OCRと画像一致を含む全ルールのカウントを確認・個別クリアできます。値は `counts.json` に保存されます。

## GitHub ActionsでEXEを作る

GitHubリポジトリ直下へファイル一式を登録し、次を実行します。

```text
Actions
→ Build Windows Integrated GUI EXE
→ Run workflow
```

成功後、Artifactsから次を取得します。

```text
ScreenImageMonitor-Windows-GUI-v6.3
```

## 配布構成

```text
ScreenImageMonitor.exe
config.json
README.md
templates/
samples/
sounds/
evidence/
```

TesseractはEXE内部へ同梱されるため、外部の `tesseract` フォルダーは不要です。
