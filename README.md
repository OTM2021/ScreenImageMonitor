# ScreenImageMonitor v1.0

Windows画面の指定範囲を常時監視し、**数字の変化**または**登録画像の表示**を検出して回数を数えるGUIアプリです。条件に一致した際は、任意で音通知と証跡スクリーンショット保存を行えます。

操作は原則として`ScreenImageMonitor.exe`のGUI内で完結します。コマンドプロンプトやBATファイルは不要です。

## 主な機能

- 画面上の数字をOCRで読み取り
- PNG／JPEGの画像一致判定
- マウス操作による監視範囲の指定
- ルールごとの独立常駐監視
- 条件一致時のカウントアップ
- 任意の音通知
- 証跡スクリーンショット保存
- 独立したカウンターウィンドウ
- カウンターのフォント・文字サイズ・太字設定
- 複数モニターおよび負の画面座標への対応
- 日本語を含む画像ファイル名・フォルダーパスへの対応

---

## 動作環境

- Windows 10／11 64ビット
- GUIを表示できるデスクトップ環境
- 監視対象が画面上に表示されていること

GitHub Actionsで生成したEXEには、PythonランタイムとTesseract OCRを同梱します。通常、利用者側でPythonやTesseractを追加インストールする必要はありません。

---

## 初回設定

1. `ScreenImageMonitor.exe`をダブルクリックします。
2. メイン画面で「設定・ルール編集」を開きます。
3. 「数字OCRルール追加」または「画像一致ルール追加」を押します。
4. ルール名、監視範囲、判定条件を設定します。
5. 「ルールへ反映」を押します。
6. 「設定を保存」を押します。
7. メイン画面へ戻り、「監視開始」を押します。

> **OCRとは**  
> 画像として表示されている文字や数字を読み取る仕組みです。本アプリでは主に画面上の数字を読み取るために使用します。

# 数字を監視する

## 1. 数字OCRルールを追加する

設定画面で次を押します。

```text
数字OCRルール追加
```

「ルール名」には、監視内容が分かる名前を入力します。

```text
処理件数
警告数値
スコア増加回数
```

## 2. 監視範囲を指定する

次を押します。

```text
画面から範囲選択
```

数字が表示される場所をマウスで囲みます。

- 左ボタンを押したままドラッグ：範囲を選択
- 左ボタンを離す：確定
- `Esc`または右クリック：キャンセル

数字の周囲に少し余白を含めると、読み取りが安定しやすくなります。ただし、別の数字や文字が入りすぎないようにしてください。

## 3. 数値条件を設定する

画面上では専門的な英字ではなく、日本語の条件名を表示します。

| 画面の表示 | 検知する条件 | 入力例 |
|---|---|---|
| 指定した数値と同じ | 読み取った数値が指定値と同じ | `10` |
| 指定した数値と異なる | 読み取った数値が指定値以外 | `0` |
| 指定した数値より大きい | 読み取った数値が指定値を超えた | `10` |
| 指定した数値以上 | 読み取った数値が指定値以上 | `10` |
| 指定した数値より小さい | 読み取った数値が指定値未満 | `10` |
| 指定した数値以下 | 読み取った数値が指定値以下 | `10` |
| 指定範囲内 | 読み取った数値が指定範囲内 | `1-10` |
| OCR結果に指定範囲の数値を含む | 読み取った文字列内の数値のどれかが指定範囲内 | `120-129` |
| 前回から数値が変わった | 安定した読み取り値が前回から変化 | 入力不要 |
| 前回より数値が増えた | 安定した読み取り値が前回より増加 | 入力不要 |
| 前回より数値が減った | 安定した読み取り値が前回より減少 | 入力不要 |

### 範囲の入力方法

範囲は1つの入力欄へ、次の形式で入力します。

```text
1-10
```

小数も使用できます。

```text
1.5-9.5
```

負の数を含む場合は、画面の案内に従って入力してください。

### OCR結果の中に対象数値が含まれる場合

次の条件を使用します。

```text
OCR結果に指定範囲の数値を含む
```

設定例：

```text
含まれる範囲：120-129
```

OCR結果が`121.1`の場合、`121.1`は120～129の範囲に含まれるため検知します。

OCR結果が次のように複数の数値を含む場合も、1つでも範囲内なら検知します。

```text
現在値 121.1 / 上限 150
```

## 4. OCRテストを実行する

次を押します。

```text
数字OCRテスト
```

テスト画面では、次を確認できます。

- OCRで読み取った文字列
- 読み取った数値の一覧
- 設定条件に一致したか
- 実際に一致した数値

正しく読めない場合は、監視範囲を選び直してください。

# 登録画像を監視する

## 1. 画像一致ルールを追加する

設定画面で次を押します。

```text
画像一致ルール追加
```

画像ルールではOCRを実行しません。登録したPNG／JPEGと監視画面を比較し、一致率で判定します。

## 2. 判定画像を登録する

次を押します。

```text
PNG/JPEGを登録...
```

使用できる形式は次のとおりです。

```text
.png
.jpg
.jpeg
```

登録画像がない場合、画像ルールは保存・監視開始できません。案内が表示された場合は、先に画像を登録してください。

画像ファイル名と保存フォルダーには日本語を使用できます。

## 3. 監視位置を指定する

画像登録後、次を押します。

```text
画面から範囲選択
```

画像ルールでは、登録画像と**同じピクセルサイズ**の枠が表示されます。

1. マウスを動かして枠を監視対象へ合わせます。
2. 左クリックで位置を確定します。
3. `Esc`または右クリックでキャンセルします。

枠の大きさは自動的に登録画像と同じになるため、手動で大きさを合わせる必要はありません。

## 4. 画像一致率を設定する

画像一致率は、登録画像と現在画面がどの程度似ていれば同じ画像と判断するかを表します。

| 設定値 | 目安 |
|---|---|
| `0.95` | かなり厳しい。ほぼ同じ画像だけを検出 |
| `0.90` | 標準的な初期値 |
| `0.80` | 少し異なっていても検出しやすい |

最初は次の値を推奨します。

```text
0.90
```

誤検出が多い場合は値を上げ、対象を検出しない場合は少し下げます。

## 5. 画像一致テストを実行する

次を押します。

```text
画像一致テスト
```

一致率、登録画像名、監視画像、検出位置を確認します。対象画像が表示されている状態で、設定した一致率を超えることを確認してください。

# 共通設定

## 連続一致回数

条件が何回続けて一致したらカウントするかを指定します。

```text
2
```

`2`の場合、2回連続で一致したときにカウントします。一瞬だけ発生したノイズによる誤検出を減らせます。

通常は`2`を推奨します。短時間だけ表示される対象を見逃す場合は`1`を試してください。

## 音通知

次にチェックを入れると、カウントアップ時に音が鳴ります。

```text
カウントアップ時に音通知する
```

使用する音声ファイル：

```text
sounds/alert.wav
```

音を変更する場合は、同じファイル名のWAVファイルへ差し替えます。

## 証跡スクリーンショット

次にチェックを入れると、カウントアップした瞬間の監視範囲を画像として保存します。

```text
カウントアップ時に証跡スクリーンショットを保存する
```

保存先：

```text
evidence
```

保存画像には、ルール名、日時、カウント数、検知した数値などがファイル名として付加されます。

# 監視を開始・停止する

設定保存後、メイン画面で次を押します。

```text
監視開始
```

各ルールは独立した監視処理として動作します。OCR処理中でも、別の画像ルールやOCRルールは可能な範囲で並行して監視します。

監視一覧の「判定詳細」には次が表示されます。

- 最後に確認した時刻
- 画面を確認した回数
- 読み取った数字または画像一致率
- 1回の確認にかかった時間

確認時刻と走査回数が更新され続けていれば、監視は動作しています。

監視を終了する場合は次を押します。

```text
監視停止
```

設定画面を開く際は、安全のため監視を停止してから編集してください。

# カウンター画面

カウント数は、メイン画面とは別のウィンドウに大きく表示されます。

初期デザイン：

```text
背景：青
文字：白
フォント：Segoe UI Light
文字サイズ：56
太字：なし
```

カウンター画面では次の操作ができます。

- ルールごとのカウント確認
- 個別の「0に戻す」
- 「全カウントをクリア」
- フォント設定

カウンター画面を閉じた場合は、メイン画面の次のボタンから再表示できます。

```text
カウンター表示
```

## フォントを変更する

カウンター画面右上の次を押します。

```text
フォント設定
```

| 項目 | 内容 |
|---|---|
| フォント | Windowsにインストールされているフォントから選択 |
| 文字サイズ | `18`～`180` |
| 太字にする | 必要な場合だけチェック |

`1234`のプレビューで表示を確認し、「保存」を押します。設定は開いているカウンターへ直ちに反映されます。

設定保存先：

```text
counter_display.json
```

`Segoe UI Light`が端末にない場合は、`Segoe UI`または`Arial`へ自動的に切り替わります。本アプリはフォントファイルを同梱・再配布しません。

# うまく動かない場合

## 数字を正しく読めない

- 数字の周囲に少し余白を含めます。
- 別の数字や文字が入らないようにします。
- 背景と文字のコントラストが高い状態で試します。
- 「数字OCRテスト」で読み取り結果を確認します。
- 表示倍率やフォントが変わった場合は、範囲を選び直します。

## 画像を検出しない

- 対象が表示されている状態で「画像一致テスト」を実行します。
- 画面の表示倍率と登録画像作成時の倍率をそろえます。
- 一致率を`0.90`から`0.85`程度へ少し下げます。
- PNG／JPEGを再登録し、監視位置を選び直します。

## 画像ファイルを読み込めない

日本語ファイル名には対応しています。ファイルが削除・移動されていないか、破損していないかを確認し、設定画面から再登録してください。

## 同じ表示を何度もカウントしない

同じ条件が表示され続けている間は、通常1回だけカウントします。一度条件から外れた後、再び一致すると次のカウントを行います。

## 監視が止まっているように見える

「判定詳細」の確認時刻と走査回数が更新されているか確認します。更新されていない場合は、一度「監視停止」を押してから「監視開始」を押します。

## Windows Defenderなどから警告される

PyInstallerで生成した未署名EXEは、環境によって警告や誤検知を受ける場合があります。組織内で配布する場合は、ソースとGitHub Actionsのビルド結果を確認し、必要に応じてコード署名を行ってください。

# GitHub ActionsでWindows EXEを作る

## リポジトリへ登録する

ZIPを展開し、内容をGitHubリポジトリの直下へアップロードします。

重要なWorkflow：

```text
.github/workflows/build-windows.yml
```

## ビルドする

1. GitHubリポジトリの`Actions`を開きます。
2. 左側の`Build Windows Integrated GUI EXE`を選択します。
3. `Run workflow`を押します。
4. 緑色の`Run workflow`をもう一度押します。
5. 緑のチェックになるまで待ちます。
6. 実行結果の下部にある`Artifacts`を開きます。

Artifact名：

```text
ScreenImageMonitor-Windows-GUI-v1.0
```

## ビルド時の検査

Workflowでは、主に次を検査します。

- Pythonソースの構文
- 必須ライブラリのインポート
- 設定ファイルの読み込み
- 数字条件の判定
- 画像ルールとOCRルールの分離
- Unicode画像パス
- 範囲選択処理
- 独立監視処理
- カウンターフォント設定
- Tesseract OCRの起動
- EXE内のTesseractと英語学習データ
- OSSライセンスファイルの収集
