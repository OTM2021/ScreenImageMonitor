# ScreenImageMonitor 統合GUI版 v6

Windows画面の指定範囲を常駐監視し、数字OCRまたは登録画像との一致でカウントアップ／音通知を行うGUIアプリです。操作は `ScreenImageMonitor.exe` だけで完結し、BATファイルは使用しません。

## v6の修正内容

### 監視範囲と登録画像の不一致対策

- 監視範囲選択を、縮小画像上の座標変換方式から**選択モニター上の1:1全画面オーバーレイ方式**へ変更
- ドラッグした1ピクセルを、そのままデスクトップ座標の1ピクセルとして保存
- 保存済み監視範囲が属するモニターを設定画面で自動選択
- 「監視範囲の現在画像」と「登録したPNG/JPEG」を左右別々に表示
- 登録画像が監視範囲より大きい場合は保存・登録を停止して修正を案内
- 画像一致テストでは、監視範囲上の検出位置を赤枠で表示
- テスト結果に監視範囲サイズ、登録画像サイズ、一致率、検出位置を表示

### 常駐監視のタイミング修正

- 全ルールを1本の順次処理ループで監視する方式を廃止
- **ルールごとに独立した監視スレッド**を使用
- OCR処理が遅くても、画像一致ルールや別のOCRルールを停止させない
- 画像一致ルールは最大約0.1秒間隔で走査
- OCRルールは前回処理完了後、設定周期に従って継続走査
- 監視一覧にミリ秒単位の最終更新時刻、走査回数、1回の処理時間を表示

## 基本操作

1. `ScreenImageMonitor.exe`を起動します。
2. メイン画面の「設定」を開きます。
3. 数字OCRまたは画像一致ルールを追加します。
4. 対象モニターを選択します。
5. 「画面からドラッグ選択」を押し、実画面上で監視範囲をドラッグします。
6. 画像ルールの場合は「PNG/JPEGを登録...」から照合画像を登録します。
7. 「画像一致テスト」で赤枠の検出位置と一致率を確認します。
8. 「ルールへ反映」後、「config.jsonへ保存」を押します。
9. メイン画面で「監視開始」を押します。

## 監視範囲の指定

選択したモニター全体が一時的に画像表示されます。監視したい範囲をドラッグし、マウスを離すと確定します。

- `Esc`：取消
- 右クリック：取消

複数モニターや、左側に配置されて負の座標を持つモニターにも対応します。

## 画像一致ルール

画像ルールはTesseract OCRを使用しません。登録したPNG／JPEGを、選択した監視範囲内からOpenCVで検索します。

対応形式：

```text
.png
.jpg
.jpeg
```

登録画像は監視範囲と同じサイズである必要はありません。監視範囲内に登録画像が収まるサイズであれば、その位置を検索します。ただし、登録画像が監視範囲より大きい場合は判定できないため、設定保存を停止します。

登録画像はアプリ横の `templates` フォルダーへコピーされます。

## 監視状態の確認

メイン画面の「判定詳細」に次が表示されます。

```text
登録画像名またはOCR結果
最終更新時刻（ミリ秒）
走査回数
1回の処理時間
```

更新時刻が連続して変化していれば、常駐監視が動作しています。

## カウンターポップアップ

EXE起動時にカウンター専用ウィンドウが開きます。閉じた場合は、メイン画面の「カウンター表示」から再表示できます。

カウント値は `counts.json` に保存され、アプリ終了後も維持されます。

## GitHub ActionsでEXEを作る

GitHubリポジトリ直下へファイル一式を登録し、次を実行します。

```text
Actions
→ Build Windows Integrated GUI EXE
→ Run workflow
```

成功後、Artifactsから次を取得します。

```text
ScreenImageMonitor-Windows-GUI-v6
```

## 配布構成

```text
ScreenImageMonitor.exe
config.json
README.md
templates/
samples/
sounds/
evidence/
```

TesseractはEXE内部へ同梱されるため、外部の`tesseract`フォルダーは不要です。
