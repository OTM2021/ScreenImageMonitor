# ScreenImageMonitor 統合GUI版 v6.2

Windows画面の指定範囲を常駐監視し、数字OCRまたは登録画像との一致を検出してカウントするGUIアプリです。音通知は別ルールではなく、各カウントルールのチェック項目として設定します。操作は `ScreenImageMonitor.exe` だけで完結し、BATファイルは使用しません。

## v6.2の変更内容

- ルール追加を「数字OCRルール」「画像一致ルール」の2種類へ集約
- すべてのルールで条件成立時にカウントアップ
- 各ルールの「カウントアップ時に音通知する」をチェックすると、カウントと同時に音を再生
- 音を鳴らさない場合はチェックを外すだけで設定可能
- 旧 `action: sound` ルールは、カウント＋音通知ルールとして自動移行
- カウンターポップアップには数字OCR・画像一致の全ルールを表示
- メイン画面の動作欄に「カウント」または「カウント＋音」を表示

## ルール設定

### 数字OCR

1. 「数字OCRルール追加」を押します。
2. 監視する画面範囲をGUIでドラッグ指定します。
3. 数値条件を設定します。
4. 必要な場合は「カウントアップ時に音通知する」をチェックします。
5. OCRテスト後に保存します。

### 画像一致

1. 「画像一致ルール追加」を押します。
2. PNG、JPGまたはJPEG画像を事前登録します。
3. 監視する画面範囲をGUIでドラッグ指定します。
4. 画像一致率を設定します。
5. 必要な場合は「カウントアップ時に音通知する」をチェックします。
6. 画像一致テスト後に保存します。

画像ルールはOCRを実行せず、登録画像とのOpenCV画像一致だけを判定します。登録画像がない場合は、保存時および監視開始時に登録を促します。

## 音通知

音通知に使用する標準ファイルは次です。

```text
sounds/alert.wav
```

ルールごとにチェックを切り替えられます。

```text
☐ カウントアップのみ
☑ カウントアップ＋音通知
```

音通知を有効にしてもカウントは必ず実行されます。

## 監視範囲

選択したモニター全体に1:1の範囲選択画面を表示します。監視対象をドラッグし、マウスを離すと確定します。

- `Esc`：取消
- 右クリック：取消

複数モニターおよび負のデスクトップ座標に対応します。

## 常駐監視

ルールごとに独立した監視スレッドを使用します。OCR処理中でも別の画像一致ルールは継続して走査します。メイン画面の判定詳細には、最終更新時刻、走査回数および処理時間が表示されます。

## カウンターポップアップ

EXE起動時に別ウィンドウで表示されます。数字OCRと画像一致を含む全ルールのカウントを確認・個別クリアできます。値は `counts.json` に保存されます。

## GitHub ActionsでEXEを作る

GitHubリポジトリ直下へファイル一式を登録し、次を実行します。

```text
Actions
→ Build Windows Integrated GUI EXE
→ Run workflow
```

成功後、Artifactsから次を取得します。

```text
ScreenImageMonitor-Windows-GUI-v6.2
```

## 配布構成

```text
ScreenImageMonitor.exe
config.json
README.md
templates/
samples/
sounds/
evidence/
```

TesseractはEXE内部へ同梱されるため、外部の `tesseract` フォルダーは不要です。
